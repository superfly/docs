title: fly mpg users rotate-password

Give a Managed Postgres user a new password and print it. This can't be
undone: apps using the old password can't open new connections, so update
their DATABASE_URL secrets afterwards. Existing sessions stay open unless
you pass --kill-sessions.

Pass --username, or pick the user from a list in a terminal. You're asked
to confirm unless you pass --yes. Without a terminal, or with --json, the
cluster ID, --username and --yes are all required.

With no cluster ID, you pick an organization (unless FLY_ORG is set) and a
cluster from lists in a terminal. Not available for v1 clusters.

## Usage
```
fly mpg users rotate-password <CLUSTER_ID> [flags]
```
## Options

```
  -h, --help              help for rotate-password
  -j, --json              JSON output
      --kill-sessions     Terminate the user's existing database sessions after rotating the password
  -u, --username string   The username whose password to rotate
  -y, --yes               Accept all confirmations (also --auto-confirm)
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
```
