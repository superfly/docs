Show or change the weekly window during which a Managed Postgres cluster
may undergo maintenance. Times are in the cluster's regional timezone. Not
available for v1 clusters.

## Usage
```
fly mpg maintenance-window [command] [flags]
```
## Available Commands
* [set](/flyctl/cmd/fly_mpg_maintenance-window_set)	 - Change a Managed Postgres cluster's maintenance window
* [show](/flyctl/cmd/fly_mpg_maintenance-window_show)	 - Show a Managed Postgres cluster's maintenance window

## Options

```
  -h, --help   help for maintenance-window
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
