---
title: fly extensions kubernetes save-kubeconfig
source_url: https://docs.fly.io/flyctl/cmd/fly_extensions_kubernetes_save-kubeconfig
---

Fetch the kubeconfig for the cluster named in the argument and write it
to a file named after the cluster, such as `my-cluster.kubeconfig.yml`,
in the current directory, or to the path given with `--output`. The file
is readable only by you and replaces any existing file at that path.

## Usage
```
fly extensions kubernetes save-kubeconfig [cluster name] [flags]
```
## Options

```
  -h, --help            help for save-kubeconfig
      --output string   The output path to save the kubeconfig file
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
