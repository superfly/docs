Provision an Upstash Vector index on the pay-as-you-go plan. In an app
directory, or with `--app`, the index is attached to that app, and the
command fails if the app already has one. Otherwise the index belongs to
an organization, which you pick from a list unless you pass `--org` or
set FLY_ORG.

You pick a similarity function and an embedding model from lists. If you
provide your own embeddings, you're asked for the number of dimensions
(default 128). There are no flags for these choices, so this command
needs a terminal. The first time you use Upstash Vector you must also
accept its terms of service; `--yes` accepts them. You may also be asked
for a name and region, unless you pass `--name` and `--region`.

For an app's index, the credentials are set as secrets on the app and
its machines restart to pick them up; if the app hasn't been deployed
yet, they take effect on its first deploy. If any of those secrets
already exist, none are set, and the values are printed for you to set
yourself.

## Usage
```
fly extensions vector create [flags]
```
## Options

```
  -a, --app string      Application name
  -c, --config string   Path to application configuration file
  -h, --help            help for create
  -n, --name string     The name of your cluster
  -o, --org string      The target Fly.io organization
  -r, --region string   The target region (see 'flyctl platform regions')
  -y, --yes             Accept all confirmations (also --auto-confirm)
```
