title: fly skills update

Re-download the Fly agent skills and refresh every file that is still as
installed. Files you have edited are left alone and listed; pass --force to
overwrite them. Only agents the skills were previously installed into are
updated unless --agent is given.

An install pinned with --ref stays on that branch, tag or commit until you
pass --ref main.

## Usage
```
fly skills update [flags]
```
## Options

```
      --agent strings   Act on exactly the named agent(s) instead of detecting them; include universal to write ~/.agents/skills. One of: universal, claude-code, codex, cursor, opencode, copilot, factory-droid, pi, antigravity. Can be repeated or comma-separated.
      --force           Overwrite files you have modified locally instead of skipping them
  -h, --help            help for update
      --ref string      Install from a branch, tag or commit SHA of superfly/skills. The pin is remembered by later update and status runs; pass --ref main to track main again.
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
