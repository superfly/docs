Get or put files from a remote VM.

## Usage
```
fly sftp [command] [flags]
```
## Available Commands
* [find](/flyctl/cmd/fly_sftp_find)	 - The SFTP FIND command lists files (from an optional root directory) on a remote VM.
* [get](/flyctl/cmd/fly_sftp_get)	 - The SFTP GET retrieves a file from a remote VM.
* [put](/flyctl/cmd/fly_sftp_put)	 - The SFTP PUT uploads a file to a remote VM.
* [shell](/flyctl/cmd/fly_sftp_shell)	 - The SFTP SHELL command brings up an interactive SFTP session to fetch and push files from/to a VM.

## Options

```
  -h, --help   help for sftp
```
