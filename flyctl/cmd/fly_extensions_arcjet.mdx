Provision and manage Arcjet


## Usage
```
fly extensions arcjet [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_extensions_arcjet_create)	 - Create an Arcjet site
* [dashboard](/flyctl/cmd/fly_extensions_arcjet_dashboard)	 - Visit the Arcjet dashboard
* [destroy](/flyctl/cmd/fly_extensions_arcjet_destroy)	 - Permanently destroy an Arcjet site
* [list](/flyctl/cmd/fly_extensions_arcjet_list)	 - List your Arcjet sites
* [status](/flyctl/cmd/fly_extensions_arcjet_status)	 - Show details about an Arcjet site setup

## Options

```
  -h, --help   help for arcjet
```

  -t, --access-token string   Fly API Access Token
