Launch and manage Redis databases managed by Upstash.com

## Usage
```
fly redis [command] [flags]
```
## Available Commands
* [connect](/flyctl/cmd/fly_redis_connect)	 - Connect to a Redis database using redis-cli
* [create](/flyctl/cmd/fly_redis_create)	 - Create an Upstash Redis database
* [dashboard](/flyctl/cmd/fly_redis_dashboard)	 - View your Upstash Redis databases on the Upstash web console
* [destroy](/flyctl/cmd/fly_redis_destroy)	 - Permanently destroy an Upstash Redis database
* [list](/flyctl/cmd/fly_redis_list)	 - List Upstash Redis databases for an organization
* [plans](/flyctl/cmd/fly_redis_plans)	 - List available Redis plans
* [proxy](/flyctl/cmd/fly_redis_proxy)	 - Proxy to a Redis database
* [reset](/flyctl/cmd/fly_redis_reset)	 - Reset the password for an Upstash Redis database
* [status](/flyctl/cmd/fly_redis_status)	 - Show status of a Redis database
* [update](/flyctl/cmd/fly_redis_update)	 - Update an Upstash Redis database
