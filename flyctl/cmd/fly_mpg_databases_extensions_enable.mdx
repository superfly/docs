Enable (install) a Postgres extension in a Managed Postgres database. The
extension goes in the schema given by --schema; add --create-schema if
that schema doesn't exist yet. For postgis_topology with no --schema, the
topology schema is used and created if needed.

With no --cluster, you pick an organization (unless FLY_ORG is set) and a
cluster from lists in a terminal; without a terminal, --cluster is required.
With no --database, the cluster's only database is used; if there are
several, you pick one in a terminal, and without a terminal --database is
required.

See available extensions with `fly mpg databases extensions list`.

## Usage
```
fly mpg databases extensions enable <EXTENSION> [flags]
```
## Options

```
  -c, --cluster string    Target cluster ID
      --create-schema     Create the schema if it does not exist
  -d, --database string   Target database within the cluster
  -h, --help              help for enable
      --schema string     Schema in which to create the extension (default: public)
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
