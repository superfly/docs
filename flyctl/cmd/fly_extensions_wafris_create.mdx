Provision a Wafris WAF for an app. Run the command in an app directory
or pass `--app`; it fails if the app already has a Wafris WAF.

The first time you use Wafris you must accept its terms of service;
`--yes` accepts them, and is required to do so without a terminal. You
may also be asked for a name and region, unless you pass `--name` and
`--region`; `--yes` skips the name prompt but not the region one.

The values Wafris provides are set as secrets on the app and its
machines restart to pick them up; if the app hasn't been deployed yet,
they take effect on its first deploy. If any of those secrets already
exist, none are set, and the values are printed for you to set yourself.

## Usage
```
fly extensions wafris create [flags]
```
## Options

```
  -a, --app string      Application name
  -c, --config string   Path to application configuration file
  -h, --help            help for create
  -n, --name string     The name of your WAF
  -o, --org string      The target Fly.io organization
  -r, --region string   The target region (see 'flyctl platform regions')
  -y, --yes             Accept all confirmations (also --auto-confirm)
```
