Permanently destroy a Fly Kubernetes cluster, given by name as the
argument. This can't be undone.

You're asked to confirm first. Pass `--yes` to skip the prompt; without
a terminal, `--yes` is required. Find cluster names with
`fly ext k8s list`.

## Usage
```
fly extensions kubernetes destroy [name] [flags]
```
## Options

```
  -h, --help   help for destroy
  -y, --yes    Accept all confirmations (also --auto-confirm)
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
