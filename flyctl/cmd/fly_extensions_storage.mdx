Provision and manage Tigris object storage buckets


## Usage
```
fly extensions storage [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_extensions_storage_create)	 - Provision a Tigris object storage bucket
* [dashboard](/flyctl/cmd/fly_extensions_storage_dashboard)	 - Visit the Tigris dashboard
* [destroy](/flyctl/cmd/fly_extensions_storage_destroy)	 - Permanently destroy a Tigris object storage bucket
* [list](/flyctl/cmd/fly_extensions_storage_list)	 - List your Tigris object storage buckets
* [status](/flyctl/cmd/fly_extensions_storage_status)	 - Show details about a Tigris storage bucket
* [update](/flyctl/cmd/fly_extensions_storage_update)	 - Update an existing Tigris object storage bucket

## Options

```
  -h, --help   help for storage
```
