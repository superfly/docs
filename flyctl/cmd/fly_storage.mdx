Provision and manage Tigris object storage buckets


## Usage
```
fly storage [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_storage_create)	 - Provision a Tigris object storage bucket
* [dashboard](/flyctl/cmd/fly_storage_dashboard)	 - Visit the Tigris dashboard
* [destroy](/flyctl/cmd/fly_storage_destroy)	 - Permanently destroy a Tigris object storage bucket
* [list](/flyctl/cmd/fly_storage_list)	 - List your Tigris object storage buckets
* [status](/flyctl/cmd/fly_storage_status)	 - Show details about a Tigris storage bucket
* [update](/flyctl/cmd/fly_storage_update)	 - Update an existing Tigris object storage bucket

## Options

```
  -h, --help   help for storage
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
