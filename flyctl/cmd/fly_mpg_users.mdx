List, create and delete database users in a Managed Postgres cluster,
change their roles, and rotate their passwords. Each user has one role:
schema_admin, writer or reader.

## Usage
```
fly mpg users [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_mpg_users_create)	 - Create a user in a Managed Postgres cluster
* [delete](/flyctl/cmd/fly_mpg_users_delete)	 - Delete a user from a Managed Postgres cluster
* [list](/flyctl/cmd/fly_mpg_users_list)	 - List users in a Managed Postgres cluster
* [rotate-password](/flyctl/cmd/fly_mpg_users_rotate-password)	 - Rotate a user's password in a Managed Postgres cluster
* [set-role](/flyctl/cmd/fly_mpg_users_set-role)	 - Change a user's role in a Managed Postgres cluster
