List and create backups of a Managed Postgres cluster. To restore a
backup into a new cluster, use `fly mpg restore`.

## Usage
```
fly mpg backup [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_mpg_backup_create)	 - Create a backup of a Managed Postgres cluster
* [list](/flyctl/cmd/fly_mpg_backup_list)	 - List backups of a Managed Postgres cluster

## Options

```
  -h, --help   help for backup
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
