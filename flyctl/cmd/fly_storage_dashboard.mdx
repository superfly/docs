Open the Tigris web console for a bucket in your browser, using a
sign-in link from Fly.io. Name the bucket as an argument, or run the
command in an app directory (or with `--app`) to use the app's bucket.
With `--org`, or with FLY_ORG set, it opens that organization's Tigris
dashboard instead, even if you name a bucket.

If you haven't accepted Tigris's terms of service yet, you're asked to;
`--yes` accepts them, and is required to do so without a terminal.

## Usage
```
fly storage dashboard [bucket_name] [flags]
```
## Options

```
  -a, --app string      Application name
  -c, --config string   Path to application configuration file
  -h, --help            help for dashboard
  -o, --org string      The target Fly.io organization
  -y, --yes             Accept all confirmations (also --auto-confirm)
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
