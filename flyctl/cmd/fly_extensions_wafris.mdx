Provision and manage Wafris WAFs (Web Application Firewalls)


## Usage
```
fly extensions wafris [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_extensions_wafris_create)	 - Provision a Wafris WAF
* [dashboard](/flyctl/cmd/fly_extensions_wafris_dashboard)	 - Visit the Wafris dashboard
* [destroy](/flyctl/cmd/fly_extensions_wafris_destroy)	 - Permanently destroy a Wafris WAF

## Options

```
  -h, --help   help for wafris
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
