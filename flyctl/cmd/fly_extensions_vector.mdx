Provision and manage Upstash Vector indexes. An index can be attached to
an app, which then gets the index's credentials as secrets, or belong
only to an organization. Create one with `fly ext vector create`.

## Usage
```
fly extensions vector [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_extensions_vector_create)	 - Provision an Upstash Vector index
* [dashboard](/flyctl/cmd/fly_extensions_vector_dashboard)	 - Open the Upstash Vector dashboard in your browser
* [destroy](/flyctl/cmd/fly_extensions_vector_destroy)	 - Permanently destroy an Upstash Vector index
* [list](/flyctl/cmd/fly_extensions_vector_list)	 - List your Upstash Vector indexes
* [status](/flyctl/cmd/fly_extensions_vector_status)	 - Show details about an Upstash Vector index
