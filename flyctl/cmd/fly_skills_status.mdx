Show, for every coding agent the Fly skills are installed into, the revision
installed and any files modified since, and whether a newer revision is
available upstream.

An install pinned with --ref is compared against that branch, tag or commit.
Pass --ref here to compare against another one without changing the pin.

## Usage
```
fly skills status [flags]
```
## Options

```
  -h, --help         help for status
  -j, --json         JSON output
      --offline      Do not contact GitHub to check for a newer revision
      --ref string   Compare against a branch, tag or commit SHA of superfly/skills instead of the remembered pin or main. Does not change the pin.
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
