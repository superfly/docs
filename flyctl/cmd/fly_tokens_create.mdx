Create Fly.io API tokens

## Usage
```
fly tokens create [command] [flags]
```
## Available Commands
* [deploy](/flyctl/cmd/fly_tokens_create_deploy)	 - Create deploy tokens
* [litefs-cloud](/flyctl/cmd/fly_tokens_create_litefs-cloud)	 - Create LiteFS Cloud tokens
* [machine-exec](/flyctl/cmd/fly_tokens_create_machine-exec)	 - Create a machine exec token
* [org](/flyctl/cmd/fly_tokens_create_org)	 - Create org deploy tokens
* [readonly](/flyctl/cmd/fly_tokens_create_readonly)	 - Create read-only org tokens
* [ssh](/flyctl/cmd/fly_tokens_create_ssh)	 - Create token for SSH'ing to a single app
* [wireguard](/flyctl/cmd/fly_tokens_create_wireguard)	 - Create a WireGuard token

## Options

```
  -h, --help   help for create
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
