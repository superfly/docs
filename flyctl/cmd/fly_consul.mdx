Enable and manage Consul clusters

## Usage
```
fly consul [command] [flags]
```
## Available Commands
* [attach](/flyctl/cmd/fly_consul_attach)	 - Attach Consul cluster to an app
* [detach](/flyctl/cmd/fly_consul_detach)	 - Detach Consul cluster from an app

## Options

```
  -h, --help   help for consul
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
