Manage Postgres extensions in a managed postgres cluster database


## Usage
```
fly mpg databases extensions [command] [flags]
```
## Available Commands
* [disable](/flyctl/cmd/fly_mpg_databases_extensions_disable)	 - Disable a Postgres extension on a database.
* [enable](/flyctl/cmd/fly_mpg_databases_extensions_enable)	 - Enable a Postgres extension on a database.
* [list](/flyctl/cmd/fly_mpg_databases_extensions_list)	 - List Postgres extensions for a database in an MPG cluster.

## Options

```
  -h, --help   help for extensions
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
