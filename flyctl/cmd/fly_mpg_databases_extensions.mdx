List, enable and disable Postgres extensions in a database of a Managed
Postgres cluster. Start with `fly mpg databases extensions list` to see which
extensions are available and installed.

## Usage
```
fly mpg databases extensions [command] [flags]
```
## Available Commands
* [disable](/flyctl/cmd/fly_mpg_databases_extensions_disable)	 - Disable a Postgres extension in a Managed Postgres database
* [enable](/flyctl/cmd/fly_mpg_databases_extensions_enable)	 - Enable a Postgres extension in a Managed Postgres database
* [list](/flyctl/cmd/fly_mpg_databases_extensions_list)	 - List Postgres extensions in a Managed Postgres database

## Options

```
  -h, --help   help for extensions
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
```
