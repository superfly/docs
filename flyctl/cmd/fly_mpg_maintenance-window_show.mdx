Show the weekly maintenance window of a Managed Postgres cluster.

## Usage
```
fly mpg maintenance-window show [CLUSTER_ID] [flags]
```
## Options

```
  -h, --help   help for show
  -j, --json   JSON output
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
