Log of all issued SSH certs

## Usage
```
fly ssh log [flags]
```
## Options

```
  -h, --help         help for log
  -j, --json         JSON output
  -o, --org string   The target Fly.io organization
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
