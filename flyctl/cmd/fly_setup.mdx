Commands that prepare a local environment for Fly.io.

The agent subcommand installs the Fly agent skills and the hosted MCP server
into the coding agents detected on this machine.

## Usage
```
fly setup [command] [flags]
```
## Available Commands
* [agent](/flyctl/cmd/fly_setup_agent)	 - Install Fly skills and the hosted MCP server into local coding agents

## Options

```
  -h, --help   help for setup
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
