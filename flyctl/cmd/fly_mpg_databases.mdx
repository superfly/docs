List and create databases in a Managed Postgres cluster, and manage
their Postgres extensions with `fly mpg databases extensions`.

## Usage
```
fly mpg databases [command] [flags]
```
## Available Commands
* [create](/flyctl/cmd/fly_mpg_databases_create)	 - Create a database in a Managed Postgres cluster
* [extensions](/flyctl/cmd/fly_mpg_databases_extensions)	 - Manage Postgres extensions in a Managed Postgres database
* [list](/flyctl/cmd/fly_mpg_databases_list)	 - List databases in a Managed Postgres cluster

## Options

```
  -h, --help   help for databases
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
