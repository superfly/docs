Permanently destroy a Managed Postgres cluster and all of its data. This
can't be undone.

You're asked to confirm unless you pass --yes; without a terminal, --yes is
required. The cluster is scheduled for deletion and may take some time to
disappear. Find cluster IDs with `fly mpg list`.

## Usage
```
fly mpg destroy <CLUSTER ID> [flags]
```
## Options

```
  -h, --help   help for destroy
  -y, --yes    Accept all confirmations (also --auto-confirm)
```
## Global Options

```
  -t, --access-token string   Fly API Access Token
      --debug                 Print additional logs and traces
      --verbose               Verbose output
```
